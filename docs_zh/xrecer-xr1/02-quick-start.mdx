# Quick Start

## 连接乐器/麦克风

将乐器连接至INPUT任一接口

可将麦克风连接至MIC IN接口

<img src="/img/manual/image3.png" alt="XRecer 操作界面" width="600"/>

## 连接音箱/耳机

将音箱连接至OUT 1/2或OUT 3/4接口

或将耳机连接至HEADPHONE OUT

<img src="/img/manual/image4.png" alt="XRecer 操作界面" width="600"/>

## 选择Preset

长按左上角 P01-01 可进入Preset列表，选择一个您喜欢的Preset

### <img src="/img/manual/image5.png" alt="XRecer 操作界面" width="600"/>

## 调音

长按TEMPO/TUNER踩钉进入调音界面，为吉他校正音准

<img src="/img/manual/image6.png" alt="XRecer 操作界面" width="600"/>

## 音色效果

点击Effect，设置Effect参数，调整至您喜欢的音色

双击Effect可以开启/关闭Effect

【提示】

点按目标参数后旋转右上角VALUE旋钮，进行精确调整

<img src="/img/manual/image7.png" alt="XRecer 操作界面" width="600"/>

## 演奏

现在您可以尽情体验XRecer XR1带来的演奏乐趣！
