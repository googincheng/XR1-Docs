# IO Spec

INPUT 1/2/3/4: 6.35mm TS, Instrument In，Impedance 10k-10M ohm，+16dBu

MIC IN: XLR In，Phantom 48V supported，0-60dB Gain

AUX IN: 3.5mm TRS，Line In

OUT 1/2: 6.35mm TRS, Impedance 700 ohm，Balanced

OUT 3/4: XLR Out, Impedance 700 ohm，Balanced

MIC OUT: XLR Out, Impedance 700 ohm，Balanced

HEADPHONES: 3.5mm TRS, 1.2 ohm（500mW@32 ohm）

SEND 1/2: 6.35mm TS Out, Impedance 700 ohm，Unbalanced

RETURN 1/2: : 6.35mm TS In, Impedance 700 ohm，Unbalanced

USB: 16 In & 16 Out USB Audio, MIDI Support

CAPX OUT: 6.35mm TS OUT, Impedance 700 ohm，Unbalanced

EXP 1/2: 6.35mm TRS In

MIDI IN/OUT：5-Din, MIDI Thru Support
