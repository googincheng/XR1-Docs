# File Manager

<ManualImage src="/img/manual/image45.png" alt="XRecer 操作界面" width="600"/>

File Manager中存放了官方和您创建的Preset、CapX、NAM以及第三方IR，您可以通过Preset组为每一场演出提前分配好Preset的顺序，以便演出时快速切换。

**All Preset**

1.  <ManualImage src="/img/manual/image46.png" alt="XRecer 操作界面" width="600"/>Patch

    -   每个Preset组（如右）中存放了16个Preset，可拖拽修改Preset组或排序

2.  Patch Location

    -   您创建的Preset将保存在这里

3.  Factory Preset

    -   Xrecer官方的Preset将保存在这里

4.  Favorite

    -   <ManualImage src="/img/manual/image47.png" alt="XRecer 操作界面" width="600"/>您可以点击 <ManualImage src="/img/manual/image48.png" alt="XRecer 操作界面" width="600"/> 将Preset收藏，方便下次快速找到

5.  Preset管理

    -   Move：拖拽即可移动

    -   Delete：点击 更多-删除

    -   Rename：点击 更多-重命名

    -   Favorite： <ManualImage src="/img/manual/image48.png" alt="XRecer 操作界面" width="600"/>

    -   Tag Management：点击 更多-标签管理，可以添加自定义的标签，方便快速筛选

    -   Copy/Paste：点击 更多-复制/粘贴

    -   Search：<ManualImage src="/img/manual/image49.png" alt="XRecer 操作界面" width="600"/>

    -   Multi-select：<ManualImage src="/img/manual/image50.png" alt="XRecer 操作界面" width="600"/>

    -   Filter：<ManualImage src="/img/manual/image51.png" alt="XRecer 操作界面" width="600"/>

## CapX

<ManualImage src="/img/manual/image52.png" alt="XRecer 操作界面" width="600"/>

通过CapX捕捉生成的音色Effect将保存在这里，同样您可以通过类似管理Preset的方式管理CapX Effect

## NAM

<ManualImage src="/img/manual/image52.png" alt="XRecer 操作界面" width="600"/>

通过Neural AMP Modeler捕捉生成的.nam模型文件将保存在这里

## IR

<ManualImage src="/img/manual/image53.png" alt="XRecer 操作界面" width="600"/>

您可以在这里管理所有的IR文件，包括Xrecer官方预置的丰富效果以及你从第三方导入的IR
