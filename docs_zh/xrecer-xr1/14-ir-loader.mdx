# IR Loader

IR File，是一种用于模拟声音在物理空间中传播、反弹、叠加的效果。想象一下，一个水泥墙面和木墙面的空间、一个10平方米和100平方米的空间，人所听到声音效果是完全不同的，而IR可以帮您复原这个真实空间的感受。您可以使用XRecer内置的空间IR，也可以导入您自己制作或者第三方的IR，让您的声音更具真实感。

## Load IR File

1.  <img src="/img/manual/image89.png" alt="XRecer 操作界面" width="600"/>在FX Chain中添加IR Loader

2.  点击进入参数设置界面，浏览并选择IR

    <img src="/img/manual/image90.png" alt="XRecer 操作界面" width="600"/>

3.  参数：

    -   Bypass：激活此IR

    -   IR File：选择IR File

    -   Phase Flip：反转此IR File的Phase

    -   LPF：Low pass filter

    -   HPF：High pass filter

    -   Delay：设置IR延迟生效的时长

    -   Pan：左右声道平衡
