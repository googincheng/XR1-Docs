# TUNER & BPM

<img src="/img/manual/image67.png" alt="XRecer 操作界面" width="600"/>

## TUNER

长按10号踩钉或通过全局下拉菜单可进入调音器。Xrecer提供了极为精准的数字调音器，精度为1cent，每一根柱体代表的偏差为10cent

1.  #### Freq 基准频率：

    -   默认为440Hz A4，范围是 415Hz 到 475Hz

2.  #### Input 输入：

    -   IN 1/2/3/4：优先级为1、2、3、4

    -   IN1、IN2、IN3、IN4

    -   MIC IN

    -   RET 1

    -   RET 2

    -   AUX IN

    -   USB IN

3.  #### 静音 Mute：

    -   开启后调音时将禁用音频输出

        <img src="/img/manual/image68.png" alt="XRecer 操作界面" width="600"/>

## BPM

连续踩踏TUNER/BPM踩钉可快速设置BPM，或通过首页顶部BPM控件可设置BPM。

1.  BPM：范围40-300

2.  Type：

    -   Global：BPM将保存到全局设置

    -   Preset：BPM将保存到当前Preset

    -   Scene：BPM将保存到当前Scene

3.  FLASH：

    -   开启后TUNER/BPM踩钉灯将按照BPM的速度闪烁
