# Global EQ

<img src="/img/manual/image29.png" alt="XRecer 操作界面" width="600"/>
    
Global EQ将对所有输出生效（除了DI干音通道），这是一个经典的5段式EQ。您可以拖拽任意一个节点进行控制。也可点击某个节点进行精细的参数调整：

1.  经典的5段式EQ编辑器
2.  点击选择节点1-5
3.  调整该频段的参数
    -   Assign：应用EQ的输出接口
    -   Type：
        -   <img src="/img/manual/image30.png" alt="XRecer 操作界面" width="20"/> Peak：平滑调整节点影响的频段
        -   <img src="/img/manual/image31.png" alt="XRecer 操作界面" width="20"/> Hi-Pass：切掉节点左侧频段（低频）
        -   <img src="/img/manual/image32.png" alt="XRecer 操作界面" width="20"/> Lo-Pass：切掉节点右侧频段（高频）
        -   <img src="/img/manual/image33.png" alt="XRecer 操作界面" width="20"/> Hi-Shelf：抑制节点右侧频段（高频）
        -   <img src="/img/manual/image34.png" alt="XRecer 操作界面" width="20"/> Lo-Shelf：抑制节点左侧频段（低频）
    -   Gain：强化/弱化此频段，即坐标Y
    -   Freq：节点所控制Frequency
    -   Q：节点覆盖的Band Width
    -   Bypass：禁用节点
4.  <img src="/img/manual/image64.png" alt="XRecer 操作界面" width="30"/> 禁用Global EQ
5.  <img src="/img/manual/image65.png" alt="XRecer 操作界面" width="30"/> 重置参数
