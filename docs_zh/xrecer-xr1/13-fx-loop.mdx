# FX LOOP

Xrecer可以将第三方Pedal接入Xrecer的FX Chain，也可将XRecer当作其他音箱的效果拓展。

## 接入第三方Pedal

<ManualImage src="/img/manual/image84.png" alt="XRecer 操作界面" width="600"/>

1.  按上图方式连接设备，如果您有多个第三方效果器，可以按虚线方式串联

2.  在FX Chain中添加FX LOOP Effect，即可将信号发送至第三方Pedal，经过处理后接入FX Chain，和其他Effect一起使用。参数见 FX LOOP Effect参数

    <ManualImage src="/img/manual/image85.png" alt="XRecer 操作界面" width="600"/> <ManualImage src="/img/manual/image86.png" alt="XRecer 操作界面" width="600"/> <ManualImage src="/img/manual/image87.png" alt="XRecer 操作界面" width="600"/>

3.  在两条FX Chain首尾插入第三方Pedal，分别设置链条1的输出为Send和链条2的输入为Return

    <ManualImage src="/img/manual/image88.png" alt="XRecer 操作界面" width="600"/>

## FX LOOP Effect参数

1.  SEND LEVEL：FX输出音量

2.  RETURN LEVEL：FX输入音量

3.  Mix：0-100，设置RETURN的音频信号和原音频信号的混合比例

4.  Pan：左右声道平衡
