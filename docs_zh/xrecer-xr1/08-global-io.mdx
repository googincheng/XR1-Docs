# Global IO

<ManualImage src="/img/manual/image66.png" alt="XRecer 操作界面" width="600"/>

1.  ### IN1/2/3/4:  6.35mm TS Input

    -   Gain：-60dB 至 +12dB

    -   IMPEDANCE：10K-10M ohm，默认1M ohm

    -   LEVEL：显示当前接口的信号输入音量

    -   其中IN1/2，IN3/4可组合为双声道输入，点击中间区域可同时选中编辑两个

2.  ### MIC IN：XLR Input

    -   Phantom 48V开关

    -   Preamp：+15dB, +25dB, +55dB

    -   LEVEL：显示当前接口的信号输入音量

3.  ### RETURN 1/2：6.35mm TS Input

    -   Gain：-60dB 至 +12dB

    -   IMPEDANCE：1M ohm

    -   Level：显示当前接口的信号输入音量

4.  ### EXP1/EXP2：6.35mm TRS Input，Expression Pedal

    -   Position：显示连接设备的最低和最高值，0-1

    -   Calibrate：点击校正Expression Pedal的最大/最小值

    -   Save：校正后点击保存

5.  ### OUT 1/2：6.35mm TRS Output Balanced

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前接口的信号输出音量

    -   MUTE：点击静音此输出

    -   点击中间区域可组合为立体声

6.  ### MIC OUT：XLR Output Balanced

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前接口的信号输出音量

    -   MUTE：点击静音此输出

7.  ### OUT 3/4：XLR Output Balanced

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前端口的信号输出音量

    -   MUTE：点击静音此输出

    -   点击中间区域可组合为立体声

8.  ### SEND 1/2：6.35mm TRS Output Unbalanced

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前输入音量

1.  ### PHONES OUT：3.5mm TRS Output

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前端口的信号输出音量，注意此处信号来源是经过效果链的

2.  ### USB：Type-C，16 IN & 16 OUT USB Audio

    -   Input Gain：-60dB 至 +12dB

    -   Output Gain：-60dB 至 +12dB

    -   IN Level：IN 1/2, IN 3/4, IN 5/6, IN 7/8

    -   OUT Level：OUT 1/2, OUT 3/4, OUT 5/6, OUT 7/8

    -   详见 接入电脑DAW软件（USB）

3.  ### MIDI IN/OUT：5-DIN MIDI IN/OUT

    -   MIDI OUT THRU开关：开启后，输入的MIDI信号将被转发至MIDI OUT连接的设备

4.  ### AUX IN：Line IN

    -   Gain：-60dB 至 +12dB

    -   Level：显示当前接口的信号输入音量

5.  ### CAPTURE OUT：专用于AI Tone Capture时的吉他DI输出，

    -   详见 AI音色模拟
