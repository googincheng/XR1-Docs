# Overview

## Top view

<ManualImage src="/img/manual/image1.png" alt="XRecer 操作界面" width="600"/>

1.  10‘’触摸屏

2.  1-8号自定义踩钉

3.  PAGE/LIVE踩钉

4.  TEMPO/TUNER踩钉

5.  全局音量旋钮

6.  Mic音量旋钮

7.  全局参数旋钮

8.  全局电平信号灯

9.  Preset/模式切换踩钉

10. Power按钮

## Rear view

<ManualImage src="/img/manual/image2.png" alt="XRecer 操作界面" width="600"/>

1.  INPUT 1/2 3/4：1/4’’ 非平衡立体声输入接口，+16dBu，10k-10M ohm

2.  MIC IN：麦克风XLR输入接口，支持PHANTOM 48V

3.  FX LOOP接口

    -   SEND 1/2：立体声输出接口，+12dBu，700 ohm

    -   RETURN 1/2：立体声输入接口，+12dBu，1M ohm

4.  1/4‘’OUT: 平衡立体声输出接口，+24dBu，700 ohm

5.  XLR OUT：平衡立体声输出接口，+24dBu，700 ohm

6.  GND LIFT：接地环路开关，隔绝Ground Loop噪声

7.  MIC OUT：麦克风XLR输出接口，+24dBu，700 ohm

8.  EXP 1/2：双Expression Pedal输入接口，支持TRS双通道

9.  MIDI IN/OUT：MIDI输入/输出接口，支持THRU

10. TYPE-C：USB TYPE-C接口，16 IN 16 OUT

11. AUX IN：3.5mm音频输入，+12dBu，10k ohm

1.  PHONES ：3.5mm音频输出，1.2 ohm（500mW@32 ohm）
