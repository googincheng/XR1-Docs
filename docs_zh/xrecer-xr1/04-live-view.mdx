# Live View

<ManualImage src="/img/manual/image39.png" alt="XRecer 操作界面" width="600"/>

## Mode Editor

1.  长按顶部栏左上角 PRESET/SCENE/STOMP，进入Mode Editor界面

2.  <ManualImage src="/img/manual/image40.png" alt="XRecer 操作界面" width="600"/>点击为上下两排踩钉分配模式

3.  COMBO模式下，1/2行踩钉分别对应两个模式

## Live View

从屏幕底部上滑，可进入Live View。您可以提前为不同曲目的不同段落的不同音色配置好参数，保存到对应的Preset/Scene，然后绑定至踩钉。在您演奏一首完整的曲目时，可以通过底部的1-8号踩钉以及PAGE踩钉，快速切换PRESET/SCENE/STOMP。

### Preset Mode

1.  <ManualImage src="/img/manual/image41.png" alt="XRecer 操作界面" width="600"/>每个Preset Patch中有16个Preset，Preset 01-08对应踩钉1A-8A，Preset 09-16对应踩钉1B-8B

### Scene Mode

1.  <ManualImage src="/img/manual/image42.png" alt="XRecer 操作界面" width="600"/>每个Preset中有16个Scene，Scene 1A-8A对应踩钉1A-8A，Scene 1B-8B对应踩钉1B-8B

2.  支持对场Scene进行重命名以及配置颜色

### Stomp Mode

1.  <ManualImage src="/img/manual/image43.png" alt="XRecer 操作界面" width="600"/>每个Effect均可绑定任一1-8（A/B）踩钉，支持多个Effect绑定至同一个踩钉

### Combo Mode

1.  <ManualImage src="/img/manual/image44.png" alt="XRecer 操作界面" width="600"/>Preset、Effect、Scene任意两个之间混合时，演出视图第一行和第二行将分别控制对应的模式，具体顺序可在【Mode Editor】界面中设置。

2.  假设Preset和Scene混合，踩钉的对应规则为

    第一页

    -   【1A】对应【P01-01】

    -   【2A】对应【P01-02】

    -   【3A】对应【P01-03】

    -   【4A】对应【P01-04】

    -   【5A】对应当前Preset下的【Scene5A】

    -   【6A】对应当前Preset下的【Scene6A】

    -   【7A】对应当前Preset下的【Scene7A】

    -   【8A】对应当前Preset下的【Scene8A】

        第二页

    -   【1B】对应【P01-09】

    -   【2B】对应【P01-10】

    -   【3B】对应【P01-11】

    -   【4B】对应【P01-12】

    -   【5B】对应当前Preset下的【Scene5B】

    -   【6B】对应当前Preset下的【Scene6B】

    -   【7B】对应当前Preset下的【Scene7B】

    -   【8B】对应当前Preset下的【Scene8B】

3.  需要注意的是：

    -   当Preset切换时，原Effect和Scene将同步切换成对应Preset下的Effect和Scene。

    -   若Scene和Effect混合，当Scene切换时，所有Effect都会恢复成Scene设置的参数
