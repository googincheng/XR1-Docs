# 异常处理

## 削波

当电平监测变红，或者声音突然变得尖锐。请按照下方步骤排查：

1.  检查全局IO中所用输入接口的电平是否过高

2.  检查效果链的输入电平是否过高

3.  按顺序检查效果链的Effect电平参数是否过高

4.  降低全局音量

## CPU占用过高

（需技术提供占用算力资源的插件/情况）

1.  系统检测到单条链上负载过重时，将自动限制添加占用计算资源过高的Effect

2.  音频信号出现glitch/pop时，请减少单条链上的Effect数量

## 噪音/电流音

1.  开启效果链INPUT的Noise Gate

2.  尝试开启Ground Lift

3.  远离高功率/无线/USB设备，避免电磁干扰

4.  使用平衡输出

5.  保证所有相关设备（XR1、Audio Interface、Speaker）共用一个电源，并避免其他电子设备接入

## 恢复出厂设置

1.  登陆账户

2.  通过云端备份您的数据

3.  恢复出厂设置

4.  重新联网，登陆账户并恢复您的数据
