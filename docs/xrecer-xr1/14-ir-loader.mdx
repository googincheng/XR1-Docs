# IR Loader

An IR file simulates how sound propagates, reflects, and combines within a physical space. For example, spaces with concrete walls and wooden walls sound very different, as do spaces measuring 10 square meters and 100 square meters. An IR can recreate the sonic character of these real-world spaces. You can use XRecer's built-in room IRs or import your own or third-party IRs to give your sound a more realistic character.

## Loading an IR File

<ManualImage className="manual-inline-icon" src="/img/manual/image89.png" alt="XRecer user interface" width="64"/> 

1.  Add an IR Loader to the FX Chain

2.  Tap the IR Loader to open its parameter settings, then browse for and select an IR

<ManualImage className="manual-figure" src="/img/manual/image90.png" alt="XRecer user interface" width="600"/>

3.  Parameters:

    -   Bypass: Sets the IR Loader's bypass state

    -   IR File: Selects an IR file

    -   Phase Flip: Inverts the polarity of the IR file

    -   LPF: Sets the low-pass filter

    -   HPF: Sets the high-pass filter

    -   Delay: Sets the delay before the IR takes effect

    -   Pan: Sets the left/right channel balance
