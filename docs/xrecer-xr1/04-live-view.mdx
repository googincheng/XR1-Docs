# Live View

## Mode Editor

1.  Tap and hold PRESET/SCENE/STOMP in the upper-left corner of the top bar to open Mode Editor.

<ManualImage className="manual-figure" src="/img/manual/image39.png" alt="XRecer user interface" width="100"/>

2. Tap to assign a mode to each row of footswitches.

    <ManualImage className="manual-figure" src="/img/manual/image40.png" alt="XRecer user interface" width="300"/>

3.  In COMBO mode, footswitch rows 1 and 2 correspond to the two assigned modes, respectively.

## Live View

Swipe up from the bottom of the screen to open Live View. You can configure tones for different sections of a song in advance, save them to the corresponding Presets or Scenes, and assign them to footswitches. During a performance, use footswitches 1–8 and the PAGE footswitch along the bottom to switch quickly between PRESET, SCENE, and STOMP modes.

### Preset Mode

1. Each Preset Patch contains 16 Presets. Presets 01–08 correspond to footswitches 1A–8A, and Presets 09–16 correspond to footswitches 1B–8B.

    <ManualImage className="manual-figure" src="/img/manual/image41.png" alt="XRecer user interface" width="300"/>

### Scene Mode

1. Each Preset contains 16 Scenes. Scenes 1A–8A correspond to footswitches 1A–8A, and Scenes 1B–8B correspond to footswitches 1B–8B.

    <ManualImage className="manual-figure" src="/img/manual/image42.png" alt="XRecer user interface" width="300"/>

2.  Scenes can be renamed and assigned colors.

### Stomp Mode

1. Each Effect block can be assigned to any footswitch from 1–8 (A/B), and multiple Effect blocks can be assigned to the same footswitch.

    <ManualImage className="manual-figure" src="/img/manual/image43.png" alt="XRecer user interface" width="300"/>

### Combo Mode

1. When any two of Preset, Stomp, and Scene modes are combined, the first and second rows in Live View control their respective modes. Set the row order in Mode Editor.

    <ManualImage className="manual-figure" src="/img/manual/image44.png" alt="XRecer user interface" width="300"/>

2.  When Preset and Scene are combined, the footswitch assignments are as follows:

    #### Page 1

    -   1A corresponds to P01-01

    -   2A corresponds to P01-02

    -   3A corresponds to P01-03

    -   4A corresponds to P01-04

    -   5A corresponds to Scene5A in the current Preset

    -   6A corresponds to Scene6A in the current Preset

    -   7A corresponds to Scene7A in the current Preset

    -   8A corresponds to Scene8A in the current Preset

    #### Page 2

    -   1B corresponds to P01-09

    -   2B corresponds to P01-10

    -   3B corresponds to P01-11

    -   4B corresponds to P01-12

    -   5B corresponds to Scene5B in the current Preset

    -   6B corresponds to Scene6B in the current Preset

    -   7B corresponds to Scene7B in the current Preset

    -   8B corresponds to Scene8B in the current Preset

> #### Note
> When you switch Presets, the Effect blocks and Scenes also switch to those associated with the selected Preset.
> When Scene and Stomp modes are combined, switching Scenes recalls the Effect block parameter values stored in the selected Scene.
