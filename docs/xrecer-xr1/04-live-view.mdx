# Live View

## Mode Editor

1.  Tap and hold PRESET/SCENE/STOMP in the upper-left corner of the top bar to open Mode Editor.

<ManualImage className="manual-figure" src="/img/manual/image39.png" alt="XRecer user interface" width="100"/>

2. Tap to assign a mode to each row of footswitches.

    <ManualImage className="manual-figure" src="/img/manual/image40.png" alt="XRecer user interface" width="300"/>

3.  In COMBO mode, footswitch rows 1 and 2 correspond to the two assigned modes, respectively.

## Live View

Swipe up from the bottom of the screen to access Live View. Prepare tones for different sections of each song in advance, save them to the corresponding Presets or Scenes, and assign them to footswitches. While you play a song, press footswitches 1–8 and the PAGE footswitch to quickly switch Presets, Scenes, and Stomps.

### Preset Mode

1. Each Preset Patch contains 16 Presets. Presets 01–08 are assigned to footswitches 1A–8A, and Presets 09–16 are assigned to footswitches 1B–8B.

    <ManualImage className="manual-figure" src="/img/manual/image41.png" alt="XRecer user interface" width="300"/>

### Scene Mode

1. Each Preset contains 16 Scenes. Scenes 1A–8A are assigned to footswitches 1A–8A, and Scenes 1B–8B are assigned to footswitches 1B–8B.

    <ManualImage className="manual-figure" src="/img/manual/image42.png" alt="XRecer user interface" width="300"/>

2.  Scenes can be renamed and assigned colors.

### Stomp Mode

1. Any effect can be assigned to any footswitch from 1A to 8B, and multiple effects can share the same footswitch.

    <ManualImage className="manual-figure" src="/img/manual/image43.png" alt="XRecer user interface" width="300"/>

### Combo Mode

1.  Combo mode mixes any two of Preset, Stomp, and Scene. The first and second rows in Live View control those two modes. Set the order in Mode Editor.
    <ManualImage className="manual-figure" src="/img/manual/image44.png" alt="XRecer user interface" width="300"/>
    
2.  When Preset and Scene are combined, the footswitch assignments are:

    #### Page 1

    -   1A = P01-01

    -   2A = P01-02

    -   3A = P01-03

    -   4A = P01-04

    -   5A = Scene 5A in the current Preset

    -   6A = Scene 6A in the current Preset

    -   7A = Scene 7A in the current Preset

    -   8A = Scene 8A in the current Preset

    #### Page 2

    -   1B = P01-09

    -   2B = P01-10

    -   3B = P01-11

    -   4B = P01-12

    -   5B = Scene 5B in the current Preset

    -   6B = Scene 6B in the current Preset

    -   7B = Scene 7B in the current Preset

    -   8B = Scene 8B in the current Preset

> #### Note

>  When you switch Presets, the effects and Scenes switch to those stored in the new Preset.

>  When Scene and Stomp are combined, switching the Scene returns all effects to the settings stored in that Scene.
