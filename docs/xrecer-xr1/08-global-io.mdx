# Global I/O

<ManualImage className="manual-figure" src="/img/manual/image66.png" alt="XRecer user interface" width="600"/>

1.  ### IN 1/2/3/4: 6.35 mm TS inputs

    -   Gain: −60 dB to +12 dB

    -   Impedance: 10 kΩ–10 MΩ; default 1 MΩ

    -   Level: input level for the selected jack

    -   IN 1/2 and IN 3/4 can each be paired as stereo. Tap between the two jacks to select and adjust both channels.

2.  ### MIC IN: XLR input

    -   Phantom 48 V: turns +48 V phantom power on or off

    -   Preamp: +15 dB, +25 dB, +55 dB

    -   Level: MIC IN signal level

3.  ### RETURN 1/2: 6.35 mm TS inputs

    -   Gain: −60 dB to +12 dB

    -   Impedance: 1 MΩ

    -   Level: input level for the selected RETURN jack

4.  ### EXP 1 / EXP 2: 6.35 mm TRS expression pedal inputs

    -   Position: shows the calibrated minimum and maximum, 0–1

    -   Calibrate: tap to measure the pedal’s minimum and maximum travel

    -   Save: tap to store the calibration

5.  ### OUT 1/2: 6.35 mm balanced TRS outputs

    -   Gain: −60 dB to +12 dB

    -   Level: output level for the selected jack

    -   Mute: mutes the selected output

    -   Tap between the two jacks to pair them as a stereo output

6.  ### MIC OUT: balanced XLR output

    -   Gain: −60 dB to +12 dB

    -   Level: MIC OUT signal level

    -   Mute: mutes MIC OUT

7.  ### OUT 3/4: balanced XLR outputs

    -   Gain: −60 dB to +12 dB

    -   Level: output level for the selected jack

    -   Mute: mutes the selected output

    -   Tap between the two jacks to pair them as a stereo output

8.  ### SEND 1/2: 6.35 mm unbalanced outputs

    -   Gain: −60 dB to +12 dB

    -   Level: current SEND level

9.  ### PHONES: 3.5 mm TRS headphone output

    -   Gain: −60 dB to +12 dB

    -   Level: headphone level. This signal is taken after the Signal Chain.

10. ### USB: USB-C, 16-in/16-out audio

    -   Input gain: −60 dB to +12 dB

    -   Output gain: −60 dB to +12 dB

    -   Input level: IN 1/2, IN 3/4, IN 5/6, IN 7/8

    -   Output level: OUT 1/2, OUT 3/4, OUT 5/6, OUT 7/8

    -   See USB Routing for details

11. ### MIDI IN/OUT: 5-pin DIN

    -   MIDI OUT THRU: when enabled, messages received at MIDI IN are forwarded to MIDI OUT

12. ### AUX IN: line input

    -   Gain: −60 dB to +12 dB

    -   Level: AUX IN signal level

13. ### CAPTURE OUT: dedicated guitar DI output for AI tone capture

    -   See CapX for details
