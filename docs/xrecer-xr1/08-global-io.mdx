# Global IO

<img className="manual-figure" src="/img/manual/image66.png" alt="XRecer user interface" width="600"/>

1.  ### IN1/2/3/4:  6.35mm TS Inputs

    -   Gain: -60dB to +12dB

    -   IMPEDANCE: 10K–10M ohm; defaults to 1M ohm

    -   LEVEL: Displays the input level for the selected connector

    -   IN1/2 and IN3/4 can each be linked as a stereo input pair. Tap the center area to select and edit both channels simultaneously.

2.  ### MIC IN: XLR input

    -   Phantom 48V power: Enables or disables phantom power

    -   Preamp: +15dB, +25dB, +55dB

    -   LEVEL: Displays the input level for the selected connector

3.  ### RETURN 1/2: 6.35mm TS inputs

    -   Gain: -60dB to +12dB

    -   IMPEDANCE: 1M ohm

    -   Level: Displays the input level for the selected connector

4.  ### EXP1/EXP2: 6.35mm TRS expression pedal inputs

    -   Position: Displays the connected device's minimum and maximum position values, 0–1

    -   Calibrate: Tap to calibrate the expression pedal's minimum and maximum values

    -   Save: Tap to save the calibration

5.  ### OUT 1/2: 6.35mm balanced TRS outputs

    -   Gain: -60dB to +12dB

    -   Level: Displays the output level for the selected connector

    -   MUTE: Mutes the selected output

    -   Tap the center area to link both channels as a stereo output pair

6.  ### MIC OUT: Balanced XLR output

    -   Gain: -60dB to +12dB

    -   Level: Displays the output level for the selected connector

    -   MUTE: Mutes the selected output

7.  ### OUT 3/4: Balanced XLR outputs

    -   Gain: -60dB to +12dB

    -   Level: Displays the output level for the selected connector

    -   MUTE: Mutes the selected output

    -   Tap the center area to link both channels as a stereo output pair

8.  ### SEND 1/2: 6.35mm unbalanced TRS outputs

    -   Gain: -60dB to +12dB

    -   Level: Displays the current output level

1.  ### PHONES OUT: 3.5mm TRS output

    -   Gain: -60dB to +12dB

    -   Level: Displays the output level for the selected connector. This signal has passed through the FX Chain.

2.  ### USB: Type-C, 16 IN & 16 OUT USB audio

    -   Input Gain: -60dB to +12dB

    -   Output Gain: -60dB to +12dB

    -   IN Level: IN 1/2, IN 3/4, IN 5/6, IN 7/8

    -   OUT Level: OUT 1/2, OUT 3/4, OUT 5/6, OUT 7/8

    -   See Connecting to Computer DAW Software (USB) for USB audio routing details

3.  ### MIDI IN/OUT: 5-pin DIN MIDI IN/OUT

    -   MIDI OUT THRU switch: When enabled, forwards incoming MIDI messages to the device connected to MIDI OUT

4.  ### AUX IN: Line input

    -   Gain: -60dB to +12dB

    -   Level: Displays the input level for the selected connector

5.  ### CAPTURE OUT: Dedicated guitar DI output for AI Tone Capture

    -   See AI Tone Modeling for capture details
