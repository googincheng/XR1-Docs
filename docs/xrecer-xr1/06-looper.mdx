# Looper

The Looper can record your performance in advance or live, continuously layering different instruments and sections. Even when you perform alone, it can create a rich live sound.

<ManualImage className="manual-inline-icon" src="/img/manual/image54.png" alt="XRecer user interface" width="64"/> 
## Adding the Looper

Find the Looper effect and add it anywhere in the Signal Chain — it records the signal with the effects before it applied.

<ManualImage className="manual-figure" src="/img/manual/image55.png" alt="XRecer user interface" width="600"/>

## Looper Controls

Tap the Looper to access the recording screen. The controls below are assigned to the matching footswitches by default.

1.  ### REC

    <ManualImage className="manual-figure" src="/img/manual/image56.png" alt="XRecer user interface" width="207"/>

    -   Initial state: The button is labeled REC. Tap it to record a new loop.

    -   Recording the first pass: the button shows Overdub. Tap it to save the track, start playback, and begin a new overdub.

    -   Track recorded, stopped: the button shows REC. Tap it to clear the old track and start a new recording.

    -   Track recorded, playing: the button shows Overdub. Tap it to start overdubbing at the current playback position.

    -   Overdubbing: tap to stop the current overdub, merge it with the previous tracks for playback, and start a new overdub.

2.  ### Playback:

    <ManualImage className="manual-figure" src="/img/manual/image57.png" alt="XRecer user interface" width="207"/>

    -   Initial state: The button is labeled Playback. Tap it to start loop playback. The button is disabled until a loop has been recorded.

    -   Playing: the button shows Stop. Tap it to stop playback.

    -   Recording, playback stopped: the button shows Playback. Tap it to finish recording and start playback.

    -   Overdubbing: the button shows Stop. Tap it to stop playback.

3.  ### Delete

    <ManualImage className="manual-figure" src="/img/manual/image58.png" alt="XRecer user interface" width="207"/>

    -   Clears all loop content recorded in the current session.

    -   If recording or playback is active, both stop.

4.  ### Doubler

    <ManualImage className="manual-figure" src="/img/manual/image59.png" alt="XRecer user interface" width="207"/>

    -   Stopped: Tap to duplicate the recorded loop.

    -   Playing: tap to duplicate the recorded track and extend the playback time.

    -   Recording, playback stopped: tap to stop and save the recording, play the previous track, and start overdubbing.

    -   Overdubbing: if the overdub runs longer than the original track, Doubler automatically copies and extends the original track. For example, you can layer a four-bar melody over a one-bar track repeated four times, without being limited by the original track length.

    -   After duplicating, tap Cut at any position to delete the audio after that point — so you are not limited to a fixed length.

5. ### Single Play

    <ManualImage className="manual-figure" src="/img/manual/image60.png" alt="XRecer user interface" width="207"/>

    -   Stopped: tap to play the loop once.

    -   Playing: tap to play to the end of the current pass, then stop.

    -   Recording, playback stopped: tap to stop and save the recording, then play the merged track once.

    -   Overdubbing: tap to stop and save the recording; playback stops after the previous track finishes.

6.  ### Half Time

    <ManualImage className="manual-figure" src="/img/manual/image61.png" alt="XRecer user interface" width="207"/>

    - Tap to set playback and recording to half speed.

7.  ### Short Cut

    <ManualImage className="manual-figure" src="/img/manual/image62.png" alt="XRecer user interface" width="207"/>
    
    - Tap to start recording a replacement track from the current playback position. Tap again to finish.

## Parameters

1.  Playback Level: −50 dB to 0 dB

2.  Doubler Level: −50 dB to 0 dB. At −5 dB, each new layer reduces the previous layer by 5 dB.

3.  High Pass: attenuates frequencies below the selected frequency.

4.  Low Pass: attenuates frequencies above the selected frequency.

5.  Threshold: when enabled, recording starts only after the input exceeds the threshold, instead of the instant you tap REC.

6.  Quantize: when enabled, the start and end of the recording are trimmed to the selected beat.

## Loop File

You can save a recording as a Loop File. Up to eight Loop Files are supported.

### Save a Loop File

1.  Tap Loop File at the top.

    <ManualImage className="manual-figure" src="/img/manual/image63.png" alt="XRecer user interface" width="100"/>

2.  Select a slot.

    <ManualImage className="manual-figure" src="/img/manual/image20.png" alt="XRecer user interface" width="400"/>

3.  Add the Loop File to the Signal Chain.
