# MIDI

## MIDI Out

On the FX Chain home screen, tap More > MIDI Out to open the MIDI output settings.

<ManualImage
  className="manual-figure"
  src="/img/manual/image80.png"
  alt="XRecer user interface"
  width="600"
/>

#### XRecer can send MIDI messages from four sources:

1.  A footswitch press. Each footswitch can be assigned up to 12 MIDI messages

2.  An expression pedal movement. Each expression pedal input can be assigned one Control Change (CC) message

3.  If you use a dual-channel EXP footswitch, each channel can be assigned one Control Change (CC) message

4.  A preset load. Up to 12 MIDI messages can be assigned

#### MIDI message parameters:

1.  Control Change (CC) message
    - MIDI channel: 0-16

    - CC\#: 0-127

    - Value: 0-127

2.  CC Toggle message
    - MIDI channel: 0-16

    - CC\#: 0-127

    - Minimum Value: 0-127

    - Maximum Value: 0-127

3.  Program Change (PC) message
    - MIDI channel: 0-16

    - Bank Select MSB (CC\#0): 0-127

    - Bank Select LSB (CC\#32): 0-127

    - Program Number: 0-127
