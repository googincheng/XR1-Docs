# Overview

## Top view

<img className="manual-figure" src="/img/manual/image1.png" alt="XRecer user interface" width="600"/>

1.  10-inch touchscreen

2.  Assignable footswitches 1–8

3.  PAGE/LIVE footswitch

4.  TEMPO/TUNER footswitch

5.  Global volume knob

6.  Mic volume knob

7.  Global parameter knob

8.  Global level meter

9.  Preset/mode footswitch

10. Power button

## Rear view

<img className="manual-figure" src="/img/manual/image2.png" alt="XRecer user interface" width="600"/>

1.  INPUT 1/2, 3/4: 1/4-inch unbalanced stereo inputs, +16dBu, 10k–10M ohm

2.  MIC IN: XLR microphone input with PHANTOM 48V support

3.  FX LOOP connections

    -   SEND 1/2: stereo outputs, +12dBu, 700 ohm

    -   RETURN 1/2: stereo inputs, +12dBu, 1M ohm

4.  1/4-inch OUT: balanced stereo outputs, +24dBu, 700 ohm

5.  XLR OUT: balanced stereo outputs, +24dBu, 700 ohm

6.  GND LIFT: ground-loop isolation switch for eliminating ground-loop noise

7.  MIC OUT: XLR microphone output, +24dBu, 700 ohm

8.  EXP 1/2: dual expression pedal inputs with dual-channel TRS support

9.  MIDI IN/OUT: MIDI input/output connections with THRU support

10. TYPE-C: USB Type-C connection, 16 IN/16 OUT

11. AUX IN: 3.5 mm audio input, +12dBu, 10k ohm

1.  PHONES: 3.5 mm audio output, 1.2 ohm (500mW@32 ohm)
