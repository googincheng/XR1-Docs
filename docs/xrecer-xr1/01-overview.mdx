# Overview

## Top Panel

<ManualImage className="manual-figure" src="/img/manual/image1.png" alt="XRecer user interface" width="600"/>

-   10-inch touchscreen

-   Assignable footswitches 1–8

-   PAGE/LIVE footswitch

-   TEMPO/TUNER footswitch

-   Global volume knob

-   Mic volume knob

-  Global parameter knob (VALUE)

-   Global level meter

-   Preset/Mode footswitch

-   Power button

## Rear Panel

<ManualImage className="manual-figure" src="/img/manual/image2.png" alt="XRecer user interface" width="600"/>

-  **INPUT 1/2 and 3/4**: 1/4-inch unbalanced stereo inputs; maximum input level +16 dBu; input impedance 10 kΩ–10 MΩ

-  **MIC IN**: XLR microphone input with +48 V phantom power

-  **FX LOOP connectors**

    -   **SEND 1/2**: stereo outputs; maximum output level +12 dBu; output impedance 700 Ω

    -   **RETURN 1/2**: stereo inputs; maximum input level +12 dBu; input impedance 1 MΩ

-  **1/4-inch OUT**: balanced stereo outputs; maximum output level +24 dBu; output impedance 700 Ω

-  **XLR OUT**: balanced stereo outputs; maximum output level +24 dBu; output impedance 700 Ω

-  **GND LIFT**: ground-lift switch for reducing ground-loop noise

-  ** MIC OUT**: XLR microphone output; maximum output level +24 dBu; output impedance 700 Ω

-  ** EXP 1/2**: dual expression pedal inputs; TRS, dual-channel

-  **MIDI IN/OUT**: MIDI input and output with THRU support

- **USB-C**: 16-in/16-out USB audio interface

- **AUX IN**: 3.5 mm auxiliary input; maximum input level +12 dBu; input impedance 10 kΩ

- **PHONES**: 3.5 mm headphone output; output impedance 1.2 Ω; 500 mW into 32 Ω
