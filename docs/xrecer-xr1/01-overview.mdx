# Overview

## Top view

<ManualImage className="manual-figure" src="/img/manual/image1.png" alt="XRecer user interface" width="600"/>

-   10-inch touchscreen

-   Assignable footswitches 1–8

-   PAGE/LIVE footswitch

-   TEMPO/TUNER footswitch

-   Global volume knob

-   Mic volume knob

-   Global parameter knob

-   Global level meter

-   Preset/mode footswitch

-   Power button

## Rear view

<ManualImage className="manual-figure" src="/img/manual/image2.png" alt="XRecer user interface" width="600"/>

-   **INPUT 1/2, 3/4**: 1/4-inch unbalanced stereo inputs, +16dBu, 10k–10M ohm

-   **MIC IN**: XLR microphone input with PHANTOM 48V support

-   **FX LOOP connections**

    -   **SEND 1/2**: stereo outputs, +12dBu, 700 ohm

    -   **RETURN 1/2**: stereo inputs, +12dBu, 1M ohm

-   **OUT 1/2**: balanced stereo outputs, +24dBu, 700 ohm

-   **OUT 3/4**: balanced stereo outputs, +24dBu, 700 ohm

-   **GND LIFT**: ground-loop isolation switch for eliminating ground-loop noise

-   **MIC OUT**:  XLR microphone output, +24dBu, 700 ohm

-   **EXP 1/2**: dual expression pedal inputs with dual-channel TRS support

-   **MIDI IN/OUT**: MIDI input/output connections with THRU support

-   **TYPE-C**: USB Type-C connection, 16 IN/16 OUT

-   **AUX IN**: 3.5 mm audio input, +12dBu, 10k ohm

-   **PHONES**: 3.5 mm audio output, 1.2 ohm (500mW@32 ohm)
