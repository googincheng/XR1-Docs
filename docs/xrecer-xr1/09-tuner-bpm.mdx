# Tuner & BPM

<ManualImage className="manual-figure" src="/img/manual/image67.png" alt="XRecer user interface" width="600"/>

## Tuner

Press and hold footswitch 10 (TEMPO/TUNER), or use the global drop-down menu, to access the Tuner.

Play a string and tune your instrument. The Tuner does not change your tone.

XRecer provides a highly accurate digital tuner with 1-cent resolution. Each bar represents a deviation of 10 cents.

1.  #### Reference pitch

    -   Default: A4 = 440 Hz. Range: 415 Hz–475 Hz.

2.  #### Input

    -   IN 1/2/3/4: priority order is IN 1, then IN 2, IN 3, IN 4

    -   IN 1, IN 2, IN 3, IN 4

    -   MIC IN

    -   RET 1

    -   RET 2

    -   AUX IN

    -   USB IN

3.  #### Mute

    -   When enabled, audio output is muted while the Tuner screen is open.

## BPM

Press the TUNER/BPM footswitch repeatedly to set the tempo, or use the BPM control at the top of the Home screen.

1.  BPM: 40–300

2.  Type:

    -   Global: stores the tempo as the global tempo

    -   Preset: stores the tempo with the current Preset

    -   Scene: stores the tempo with the current Scene

3.  FLASH:

    -   When enabled, the TUNER/BPM footswitch LED flashes in time with the tempo
