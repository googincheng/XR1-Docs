# TUNER & BPM

<ManualImage className="manual-figure" src="/img/manual/image67.png" alt="XRecer user interface" width="600"/>

## TUNER

Press and hold footswitch 10, or use the global drop-down menu, to open the tuner. The XRecer tuner provides 1-cent precision, and each bar represents 10 cents of pitch deviation.

1.  #### Freq Reference Pitch:

    -   Sets the tuner reference pitch. The default is A4 = 440Hz; the range is 415Hz to 475Hz

2.  #### Input:

    -   IN 1/2/3/4: Input priority is 1, 2, 3, 4

    -   IN1, IN2, IN3, IN4

    -   MIC IN

    -   RET 1

    -   RET 2

    -   AUX IN

    -   USB IN

3.  #### Mute:

    -   When enabled, mutes the audio output while the tuner is active

## BPM

Tap the TUNER/BPM footswitch repeatedly to set the tempo, or use the BPM control at the top of the Home screen.

1.  **BPM**: Sets the tempo; range 40–300

2.  **Type**:

    -   **Global**: Saves the BPM to the global settings

    -   **Preset**: Saves the BPM to the current Preset

    -   **Scene**: Saves the BPM to the current Scene

3.  **FLASH**:

    -   When enabled, the TUNER/BPM footswitch LED flashes in time with the current BPM
