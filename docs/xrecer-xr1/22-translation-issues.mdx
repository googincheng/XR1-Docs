# Translation Questions and Source Issues

This file records issues found while translating the supplied Chinese MDX files. Line numbers refer to the original files in `xrecer-xr1.zip`.

The English files preserve the supplied technical values and mappings unless the source contained an obvious wording error. Missing specifications and uncertain product behavior have not been invented.

## Behavior Requiring Product Confirmation

### Overview, Quick Start, and FX Chain

- `02-quick-start.mdx:19–21` — Output names (`OUT 1/2`, `OUT 3/4`, and `HEADPHONE OUT`) do not match all names used in `01-overview.mdx`. Use the exact chassis labels throughout.
- `02-quick-start.mdx:41` and `03-fx-chain.mdx:76–78` — Double-tap is described both as an on/off action and as bypass/mute behavior. Confirm the actual state transition.
- `03-fx-chain.mdx:48` — Confirm whether `1/2 page` means Page 1 of 2 or two available pages.
- `03-fx-chain.mdx:55–58` — `MIC OUT Volume` conflicts with a description of microphone input level. Confirm which level is controlled and which screen opens after press-and-hold.
- `03-fx-chain.mdx:62` — `CapX Out` is not fully documented in the hardware overview.
- `03-fx-chain.mdx:166` — Feedback and Mix/Blend have different technical functions but share one definition.
- `03-fx-chain.mdx:191` — The meaning of EQ `Assign` and the available destinations are unclear.
- `03-fx-chain.mdx:201` — The source describes Bypass as filtering a band. The English translation uses “disables this EQ band”; confirm actual behavior.
- `03-fx-chain.mdx:206` — Confirm that Bluetooth audio routing is implemented in the production firmware.
- `03-fx-chain.mdx:227` — Expression-pedal calibration appears under general FX Chain input parameters; confirm when this parameter is available.
- `03-fx-chain.mdx:242–249` — LEVEL, GROUND LIFT, and MIDI THRU indentation suggests they may be children of SOLO or an output block. Confirm the intended hierarchy and applicable outputs.
- `03-fx-chain.mdx:297` — Crossover Mode does not state which path receives the high-pass or low-pass signal.
- `04-live-view.mdx:39` — Combo mode uses `Effect` where the mode name elsewhere is `Stomp`. Confirm the final UI term.
- `05-file-manager.mdx:17` — Confirm whether dragging changes Preset order, Preset-bank membership, or both.
- `05-file-manager.mdx:59` — NAM and CapX reference the same image path (`image52.png`); confirm that both references are correct.

### Looper

- `06-looper.mdx:41` — It is unclear whether Stop affects playback only or also stops an active recording.
- `06-looper.mdx:61, 71, 75` — Confirm the final UI labels. The English translation uses `One Shot` and `Half Speed` for consistency with MIDI; `Short Cut` is retained as supplied.
- `06-looper.mdx:81–87` — High-Pass and Low-Pass ranges are missing. Confirm whether level endpoints are inclusive and whether `Doubler Level` is attenuation per layer.
- `06-looper.mdx:57` — Confirm the exact extension behavior when an overdub exceeds the original loop length.
- `06-looper.mdx:95` — Confirm whether the limit of eight applies to files, tracks, simultaneous playback, or storage slots.

### Global EQ and Global I/O

- `07-global-eq.mdx:29–31` — Shelf filters are described only as attenuation. Confirm whether positive gain is supported.
- `08-global-io.mdx:23` — Add a +48 V phantom-power compatibility and connection warning.
- `08-global-io.mdx:73` — `TRS Output Unbalanced` requires confirmation of the actual connector wiring.
- `08-global-io.mdx:91–93` — The device is described as 16-in/16-out USB audio, but meters are listed only through channels 7/8.

### Tuner, BPM, CapX, and USB

- `09-tuner-bpm.mdx:13` — Explain how 1-cent tuning precision relates to indicator bars representing 10 cents each.
- `09-tuner-bpm.mdx:21–23` — Clarify how automatic input priority relates to manual input selection.
- `10-capx.mdx:25–27, 37` — Define the relationship between Inst Level, Cap Level, Wet Signal, and clipping detection.
- `10-capx.mdx:43` — CapX is described as simulating a stompbox even though the workflow also mentions tube amplifiers. Confirm the supported target types.
- `10-capx.mdx:49` — Confirm the exact UI capitalization of `Not good Enough, try again`.
- `10-capx.mdx:87` — A download action is mentioned, but no ASIO driver URL is provided.

### MIDI

- `11-midi.mdx:57` — CC#51 and CC#53 are absent from the Looper mapping. Confirm whether they are intentionally unused.
- `11-midi.mdx:57` — The Preset formula can produce values up to 2159. Define the valid Preset range and out-of-range handling.
- `11-midi.mdx:57` — Confirm what CC#44 values 0/1/2 change when selecting Global/Preset/Scene.
- `11-midi.mdx:57` — Confirm whether `Short Cut` is an exact UI label, a translation of replace/punch-in, or a typo for `Shortcut`.

### Expression Pedal, FX Loop, and IR Loader

- `12-expression-pedal.mdx:51–59` — Define `x%`, interpolation between Min and Max, and behavior exactly at activation/bypass thresholds.
- `13-fx-loop.mdx:21` — The two-FX-Chain connection topology is not sufficiently clear to wire safely without a diagram.
- `13-fx-loop.mdx:27–33` — SEND, RETURN, and Pan ranges/units are missing. Confirm whether Mix 0–100 is a percentage and define both endpoints.
- `14-ir-loader.mdx:21` — The source says Bypass activates the IR, which is contradictory. The English translation uses “bypasses this IR”; confirm firmware behavior.
- `14-ir-loader.mdx:25` — Confirm whether Phase Flip is a polarity inversion.
- `14-ir-loader.mdx:27–33` — LPF, HPF, Delay, and Pan ranges/units are missing.
- `15-settings.mdx:9` — Login and Cloud Storage contain only `/`; Wi-Fi `2.4G/5G` should identify GHz bands.
