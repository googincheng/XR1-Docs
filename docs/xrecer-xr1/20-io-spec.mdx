# I/O Specifications

INPUT 1/2/3/4: 6.35 mm TS, instrument input, 10 kΩ–10 MΩ impedance, +16 dBu

MIC IN: XLR input, 48 V phantom power, 0–60 dB gain

AUX IN: 3.5 mm TRS, line input

OUT 1/2: 6.35 mm TRS, 700 Ω impedance, balanced

OUT 3/4: XLR output, 700 Ω impedance, balanced

MIC OUT: XLR output, 700 Ω impedance, balanced

HEADPHONES: 3.5 mm TRS, 1.2 Ω (500 mW @ 32 Ω)

SEND 1/2: 6.35 mm TS output, 700 Ω impedance, unbalanced

RETURN 1/2: 6.35 mm TS input, 700 Ω impedance, unbalanced

USB: 16-in/16-out USB audio, MIDI support

CAPX OUT: 6.35 mm TS output, 700 Ω impedance, unbalanced

EXP 1/2: 6.35 mm TRS input

MIDI IN/OUT: 5-pin DIN, MIDI Thru support
