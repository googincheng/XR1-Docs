# I/O Specifications

INPUT 1/2/3/4: 6.35 mm TS instrument inputs; 10 kΩ–10 MΩ; +16 dBu

MIC IN: XLR; +48 V phantom power; 0–60 dB gain

AUX IN: 3.5 mm TRS line input

OUT 1/2: 6.35 mm TRS balanced outputs; 700 Ω

OUT 3/4: XLR balanced outputs; 700 Ω

MIC OUT: XLR balanced output; 700 Ω

PHONES: 3.5 mm TRS; 1.2 Ω (500 mW into 32 Ω)

SEND 1/2: 6.35 mm TS unbalanced outputs; 700 Ω

RETURN 1/2: 6.35 mm TS unbalanced inputs; 700 Ω

USB: 16-in/16-out USB audio with MIDI

CAPX OUT: 6.35 mm TS unbalanced output; 700 Ω

EXP 1/2: 6.35 mm TRS inputs

MIDI IN/OUT: 5-pin DIN with MIDI THRU
