XRecer provides a 16-in/16-out USB audio interface. The diagram on the right shows the USB audio routing:

### Outputs:

1. By default, XRecer USB OUT 1/2, 3/4, and 5/6 (left/right channels) carry the dry DI signals from MIC IN and INPUT 1/2/3/4.

<ManualImage className="manual-figure" src="/img/manual/image77.png" alt="XRecer user interface" width="300"/>

2.  Select XRecer USB OUT 1/2, 3/4, or 5/6 (left/right channels) in your DAW software to receive the corresponding dry DI signal.

3.  For the remaining output channels, set the Output in the FX Chain to select the audio signal to send.

### Inputs:

1.  By default, XRecer USB IN 1/2 is routed to XRecer OUT 1/2, OUT 3/4 (left/right channels), and Phones. This lets you play backing tracks from a computer by connecting the USB cable, with no additional setup.

1.  For the remaining USB input channels, assign the desired USB IN channel to an FX Chain input.

## DAW Setup

1. Using GarageBand® as an example, first select XRecer as the input device. To process the signal in the DAW and route it back to XRecer, also select XRecer as the output device.

<ManualImage className="manual-figure" src="/img/manual/image78.png" alt="XRecer user interface" width="600"/>

2. Set the track's USB audio input and output channels.

<ManualImage className="manual-figure" src="/img/manual/image79.png" alt="XRecer user interface" width="600"/>

3.  The DAW track can now receive audio from XRecer.

4.  If you select custom channels USB IN (3–16)/OUT (7–16), ensure that the corresponding input/output connectors are configured in the FX Chain.
