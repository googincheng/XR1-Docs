## USB Routing

XRecer is a 16-in/16-out USB audio interface. The diagram on the right shows the USB signal flow.

### Outputs (XRecer to computer)

1. By default, XRecer USB OUT 1/2, 3/4, and 5/6 (left/right channels) carry the dry DI signals from MIC IN and INPUT 1/2/3/4.

<ManualImage className="manual-figure" src="/img/manual/image77.png" alt="XRecer user interface" width="300"/>

2.  Select XRecer USB OUT 1/2, 3/4, or 5/6 (left/right channels) in your DAW software to receive the corresponding dry DI signal.

3.  Assign the remaining USB output channels in the Signal Chain output settings.

### Inputs (computer to XRecer)

1.  By default, USB IN 1/2 is routed to OUT 1/2, OUT 3/4, and PHONES — so you can play backing tracks from your computer with no extra setup. Just connect the USB cable.

2.  Assign the remaining USB input channels as Signal Chain inputs.

## DAW Setup

1. Using GarageBand® as an example, select XRecer as the input device. To process audio in the DAW and return it to XRecer, also select XRecer as the output device.

<ManualImage className="manual-figure" src="/img/manual/image78.png" alt="XRecer user interface" width="600"/>

2.  On each track, select the USB input and output channels you need.

<ManualImage className="manual-figure" src="/img/manual/image79.png" alt="XRecer user interface" width="600"/>

3.  The DAW track can now receive audio from XRecer.

4.  If you use USB IN 3–16 or USB OUT 7–16, assign those channels in the Signal Chain.
