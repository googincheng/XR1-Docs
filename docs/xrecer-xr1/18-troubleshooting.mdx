# Troubleshooting

## Clipping

If a level meter turns red or the sound suddenly becomes harsh, use the following steps to identify and correct the source of the clipping:

1.  In Global I/O, check whether the level of the input in use is too high.

2.  Check whether the effect-chain input level is too high.

3.  Check the level parameter of each effect in the chain, one at a time, to identify any excessive level.

4.  Reduce the global volume.

## High CPU Usage

(Engineering input required: plugins/scenarios that consume substantial processing resources)

1.  When the system detects excessive load on a single chain, it automatically restricts the addition of effects that require substantial processing resources.

2.  If audio glitches or pops occur, reduce the number of effects on the affected chain.

## Noise / Electrical Hum

1.  Enable the Noise Gate at the effect-chain INPUT.

2.  Try enabling Ground Lift.

3.  Keep the unit away from high-power equipment, wireless devices, and USB devices to reduce electromagnetic interference.

4.  Use balanced outputs.

5.  Connect all related devices (XR1, audio interface, and speaker) to the same power source. Avoid connecting unrelated electronic devices to that power source.

## Factory Reset

1.  Sign in to your account.

2.  Back up your data to the cloud.

3.  Perform the factory reset.

4.  Reconnect to the network, sign in to your account, and restore your data.
