# Troubleshooting

## Clipping

If a level meter turns red, or the sound suddenly becomes harsh, check the following:

1.  In Global I/O, check whether the input you are using is too hot.

2.  Check the Signal Chain input level.

3.  Check the level of each effect in the chain, one at a time.

4.  Lower the global volume.

## High CPU Usage

(Engineering still needs to list which effects use the most CPU.)

1.  If one path is too heavy, the system stops you from adding more high-CPU effects to that path.

2.  If you hear glitches or pops, remove effects from that path.

## Noise / Hum

1.  Enable the noise gate on the Signal Chain input.

2.  Try Ground Lift.

3.  Keep the unit away from high-power, wireless, and USB devices to avoid electromagnetic interference.

4.  Use balanced outputs.

5.  Make sure all related devices (XR1, audio interface, speakers) share the same power source, and avoid plugging in other electronic devices.

## Factory Reset

1.  Sign in to your account.

2.  Back up your data to the cloud.

3.  Perform a factory reset.

4.  Reconnect to the network, sign in, and restore your data.
