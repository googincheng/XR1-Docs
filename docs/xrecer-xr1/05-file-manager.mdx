# File Manager

<img className="manual-figure" src="/img/manual/image45.png" alt="XRecer user interface" width="600"/>

File Manager stores factory and user-created Presets, CapX files, NAM files, and third-party IRs. You can organize Presets into a Preset group before a performance for quick switching on stage.

## All Preset

<img className="manual-figure" src="/img/manual/image46.png" alt="XRecer user interface" width="264"/>

1. Patch

    -   Each Preset group (shown at right) contains 16 Presets. Drag the Preset groups to edit or reorder them.

2.  Patch Location

    -   Presets you create are saved here.

3.  Factory Preset

    -   Official XRecer Presets are stored here.

4.  Favorite

    -   Tap <img className="manual-inline-icon" src="/img/manual/image48.png" alt="XRecer user interface" width="24"/> to add a Preset to Favorites for quick access.

    <img className="manual-figure" src="/img/manual/image47.png" alt="XRecer user interface" width="400"/>

5.  Preset Management

    -   Move: drag a Preset to move it.

    -   Delete: tap More > Delete.

    -   Rename: tap More > Rename.

    -   Favorite: <img className="manual-inline-icon" src="/img/manual/image48.png" alt="XRecer user interface" width="24"/>

    -   Tag Management: tap More > Tag Management to add custom tags for quick filtering.

    -   Copy/Paste: tap More > Copy/Paste.

    -   Search: <img className="manual-inline-icon" src="/img/manual/image49.png" alt="XRecer user interface" width="24"/>

    -   Multi-select: <img className="manual-inline-icon" src="/img/manual/image50.png" alt="XRecer user interface" width="24"/>

    -   Filter: <img className="manual-inline-icon" src="/img/manual/image51.png" alt="XRecer user interface" width="24"/>

## CapX

<img className="manual-figure" src="/img/manual/image52.png" alt="XRecer user interface" width="600"/>

Effects created from CapX captures are saved here. You can manage CapX Effects in the same way as Presets.

## NAM

<img className="manual-figure" src="/img/manual/image52.png" alt="XRecer user interface" width="600"/>

NAM model files generated by Neural Amp Modeler captures are saved here.

## IR

<img className="manual-figure" src="/img/manual/image53.png" alt="XRecer user interface" width="600"/>

You can manage all IR files here, including an extensive selection of official XRecer factory IRs and third-party IRs.
