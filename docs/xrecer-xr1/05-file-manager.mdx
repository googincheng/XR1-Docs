# File Manager

<ManualImage className="manual-figure" src="/img/manual/image45.png" alt="XRecer user interface" width="600"/>

File Manager stores factory Presets and the Presets you create, plus CapX, NAM, and third-party IRs. Use Preset groups to arrange the Preset order for each show in advance, so you can switch quickly during the performance.

## All Preset

<ManualImage className="manual-figure" src="/img/manual/image46.png" alt="XRecer user interface" width="264"/>

1.  #### Patch

    -   Each Preset group (shown on the right) holds 16 Presets. Drag to rearrange the groups or the order.

2.  #### Patch Location

    -   Presets you create are stored here.

3.  #### Factory Preset

    -   Official XRecer Presets are stored here.

4.  #### Favorite

    -   Tap <ManualImage className="manual-inline-icon" src="/img/manual/image48.png" alt="XRecer user interface" width="24"/> to add a Preset to your Favorites.

    <ManualImage className="manual-figure" src="/img/manual/image47.png" alt="XRecer user interface" width="400"/>

5.  #### Preset Management

    -   Move: drag a Preset to a new location.

    -   Delete: tap More > Delete.

    -   Rename: tap More > Rename.

    -   Favorite: <ManualImage className="manual-inline-icon" src="/img/manual/image48.png" alt="XRecer user interface" width="24"/>

    -   Tag Management: tap More > Tag Management to add custom tags, so you can filter Presets quickly.

    -   Copy / Paste: tap More > Copy/Paste.

    -   Search: <ManualImage className="manual-inline-icon" src="/img/manual/image49.png" alt="XRecer user interface" width="24"/>

    -   Multi-select: <ManualImage className="manual-inline-icon" src="/img/manual/image50.png" alt="XRecer user interface" width="24"/>

    -   Filter: <ManualImage className="manual-inline-icon" src="/img/manual/image51.png" alt="XRecer user interface" width="24"/>

## CapX

<ManualImage className="manual-figure" src="/img/manual/image52.png" alt="XRecer user interface" width="600"/>

Tones created with CapX are stored here. Manage them in the same way as Presets.

## NAM

<ManualImage className="manual-figure" src="/img/manual/image52.png" alt="XRecer user interface" width="600"/>

`.nam` model files created with Neural Amp Modeler are stored here.

## IR

<ManualImage className="manual-figure" src="/img/manual/image53.png" alt="XRecer user interface" width="600"/>

Manage factory IRs and imported third-party IRs here.
