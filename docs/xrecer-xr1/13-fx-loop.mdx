# FX Loop

You can place third-party pedals in the XRecer Signal Chain, or use XRecer as extra effects for another amp or speaker system.

## Connect a Third-Party Pedal



<ManualImage className="manual-figure" src="/img/manual/image84.png" alt="XRecer user interface" width="600"/>

1.  Connect the equipment as shown. If you use more than one pedal, connect them in series along the dashed line.

2.  Add an FX Loop effect to the Signal Chain to send audio to the external pedal and return it. See FX Loop Effect Parameters.

3.  To place a pedal between two paths, set path 1 output to SEND and path 2 input to RETURN.

<ManualImage className="manual-figure" src="/img/manual/image88.png" alt="XRecer user interface" width="600"/>

## FX Loop Effect Parameters

1.  SEND LEVEL: level sent to the external device

2.  RETURN LEVEL: level received from the external device

3.  Mix: 0–100. Balance between the return signal and the dry signal

4.  Pan: left/right balance of the returned signal
