# FX LOOP

XRecer allows you to integrate third-party pedals into its FX Chain or expand the effects capabilities of other amplifiers.

## Connecting Third-Party Pedals

<ManualImage className="manual-figure" src="/img/manual/image84.png" alt="XRecer user interface" width="600"/>

1.  Connect the devices as shown above. If you have multiple third-party effects units, connect them in series as indicated by the dashed line

2.  Add an FX Loop effect to the FX Chain to route the signal through a third-party pedal and return the processed signal to the FX Chain for use with other effects. For parameter details, see FX LOOP Effect Parameters

3.  Insert a third-party pedal between the end of one FX Chain and the beginning of another. Set the output of Chain 1 to Send and the input of Chain 2 to Return

<ManualImage className="manual-figure" src="/img/manual/image88.png" alt="XRecer user interface" width="600"/>

## FX LOOP Effect Parameters

1.  SEND LEVEL: Sets the FX Loop Send output level

2.  RETURN LEVEL: Sets the FX Loop Return input level

3.  Mix: 0-100. Sets the balance between the FX Loop Return signal and the dry signal

4.  Pan: Sets the left/right channel balance
