# Expression Pedal

An expression pedal outputs a continuous control signal, so it is often used to control parameter values precisely — for live effects such as wah and sustain.

## Expression Pedal Types

XR1 supports:

1.  Dual footswitch

2.  TRS expression pedal

3.  TRS expression pedal + switch

4.  Single footswitch

## Connect an Expression Pedal

1.  Connect the pedal with a TRS cable.

2.  Check the pedal’s own manual for wiring. Single TRS, dual TRS, and Y-cable connections are supported.

## Calibrate an Expression Pedal

<ManualImage className="manual-figure" src="/img/manual/image81.png" alt="XRecer user interface" width="600"/>

2.  Tap the EXP 1 or EXP 2 input you used.

3.  Tap Calibrate.

4.  Move the pedal from heel to toe. XRecer measures the minimum and maximum.

5.  Tap Save.

6.  If you use a dual-channel pedal or more than one pedal, calibrate each input separately.

## Assign an Expression Pedal

1. **Entrance**: On the Effect Parameter screen, tap More > Expression Pedal

    <ManualImage className="manual-figure" src="/img/manual/image82.png" alt="XRecer user interface" width="600"/>

2. **Assign**: Select the parameter you want to assign, then configure the mapping between the expression pedal position and the effect parameter value

3. **Continuous parameters**:

    <ManualImage className="manual-figure" src="/img/manual/image83.png" alt="XRecer user interface" width="600"/>

    -   **Minimum**: 0% by default. When the expression pedal position is x%, the corresponding parameter is set to its minimum value

    -   **Maximum**: 100% by default. When the expression pedal position is x%, the corresponding parameter is set to its maximum value

4.  **On/off parameters**:

    -   **Minimum**: 0% by default. When the expression pedal position is &lt; x%, the effect is bypassed

    -   **Maximum**: 100% by default. When the expression pedal position is &gt; x%, the effect is active
