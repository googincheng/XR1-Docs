# FX Chain

<ManualImage className="manual-figure" src="/img/manual/image8.png" alt="XRecer user interface" width="600"/>

## Overview

<ManualImage className="manual-figure" src="/img/manual/image9.png" alt="XRecer user interface" width="300"/>

1.  #### Scene/Preset/Stomp/Combo modes:

    -   These modes make it easy to switch tones quickly while performing.
    -   Four modes are available: Scene, Preset, Stomp, and Combo.
    -   Tap and hold to open Mode Editor and create a Combo mode.
    -   See Live View for details.

<ManualImage className="manual-figure" src="/img/manual/image10.png" alt="XRecer user interface" width="520"/>

2.  #### Preset Number

    -   The Preset number P01-12 consists of two parts.
    -   P01 is the Patch number. Each Patch contains 16 Presets.
    -   12 is the Preset number within the current Patch.
    -   Tap to browse all Presets.
    -   An \* indicates unsaved changes.

3.  #### Save Preset button

    -   Save: tap to save all changes to the Preset.
    -   Save As: tap to create and save a new Preset.

4.  #### More button

    -   Copy Preset/Scene button: tap to copy all parameters from the current Preset/Scene.
    -   Paste Preset/Scene button: tap to paste the copied parameters into the current Preset/Scene.
    -   Performance Mode button: see item 1.
    -   MIDI Output: tap to edit the MIDI messages sent by the footswitches and expression pedal for controlling other devices. See MIDI Output for details.

<ManualImage className="manual-figure" src="/img/manual/image11.png" alt="XRecer user interface" width="160"/>

5.  #### Scene button

    -   You can save different FX Chain settings to Scenes for quick recall. Up to 16 Scenes are supported: 1A–8A and 1B–8B (pages 1/2).
    -   In Scene mode, tap this button to switch Scenes.

6.  #### Undo/Redo buttons

<ManualImage className="manual-figure" src="/img/manual/image12.png" alt="XRecer user interface" width="523"/>

7.  #### MIC OUT volume

    -   Microphone output volume
    -   Tap and hold the MIC OUT volume control to open the dedicated microphone FX Chain, which has its own input and output routing.

8.  #### Global output volume

    -   Sets the volume for Out 1/2, Out 3/4, Send 1/2, Phones Out, CapX Out, and USB Out.

9.  #### BPM

    -   Displays the tempo in beats per minute (BPM). The tempo can be set independently for the Preset, Scene, and global settings.

10.  #### Preset name

<ManualImage className="manual-inline-icon" src="/img/manual/image13.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image14.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image15.png" alt="XRecer user interface" width="48"/>

11.  #### Effect block

    -   XRecer includes an extensive selection of effect models designed to recreate the character of analog effects. Select an Effect block and adjust its parameters to create your own tone.
    -   Tap: opens the parameter editor. See Parameter Editing for details.
    -   Double-tap: toggles the Effect block's bypass state.
        -   Bypass: disables this Effect, as shown in Figure 2.
        -   Mute: interrupts the entire audio signal path, as shown in Figure 3.
    -   Tap and hold, then drag to move the Effect block within the FX Chain.
    -   Tap and hold to open a menu containing:
        -   Copy/Paste
        -   Replace Effect
        -   Rename

  <ManualImage className="manual-inline-icon" src="/img/manual/image16.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image17.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image18.png" alt="XRecer user interface" width="48"/>

12.  #### FX Chain input block

    -   Tap + to assign an input to the FX Chain. Multiple input sources can be selected.
    -   Supports stereo (Figure 2) and mono (Figure 3).
    -   Double-tap to interrupt the input (Figure 4).
    -   After selecting an input, tap it to open its parameter editor. See Input Connection Parameters for details.
    -   Tap and hold, then drag to create a Split/Merge.

13.  #### FX Chain output block: same as input

<ManualImage className="manual-figure" src="/img/manual/image19.png" alt="XRecer user interface" width="600"/>

14.  #### Split/Merge

    -   Split/Merge lets you combine Effect blocks in series and parallel for a wider range of tones and more precise control.
    -   Tap and hold, then drag the Split button to create a split signal path.
    -   Tap and hold, then drag the Merge button to merge this signal path into another.
    -   Tap a Split/Merge point to adjust its parameters.
    -   Tap and hold, then drag a Split/Merge point to change its position.
    -   Series/parallel routing is supported only between two adjacent signal paths. Nonadjacent paths, such as paths 1 and 3, cannot be split or merged.

15.  #### Tap an empty area to add an Effect block

<ManualImage className="manual-figure" src="/img/manual/image20.png" alt="XRecer user interface" width="600"/>

16.  #### LOOP signal path

    -   Tap the input and select LOOP to create a LOOP signal path. You can place recorded passages on this path and layer multiple Loop Files during your performance.

### Assigning a Footswitch

<ManualImage className="manual-figure" src="/img/manual/image23.png" alt="XRecer user interface" width="600"/>

Open the Effect block's parameter editor, then use the control in the upper-right corner to assign a footswitch.

### Parameter Definitions

Common parameters

-   Gain: controls the gain of the selected device.
-   Drive/Overdrive: controls the amount of overdrive applied by the selected device.
-   Tone/Treble: controls the high frequencies. This parameter can allow all high frequencies to pass or substantially reduce the high and upper-mid frequencies.
-   Volume/Master: sets the overall volume of the selected device.
-   Comp: determines the amount of gain reduction.
-   Threshold: sets the threshold.
-   Rate: adjusts the effect rate. Higher settings produce a faster rate.
-   Depth: adjusts the intensity of the modulation effect. Higher settings produce a more pronounced effect.
-   Sync: synchronizes the effect rate to the current BPM.
-   Feedback/Mix/Blend: adjusts the effect proportion. Higher settings increase the amount of the processed signal in the mix.
-   Decay: sets how long the effect lasts.
-   Pre-Delay: sets the time before the effect begins.
-   High-Pass/Low-Pass: controls the frequency range of the high-pass and low-pass filters.
-   Bypass: bypasses the entire Effect block.
-   Bass/Mid/Treble: controls the low-, mid-, and high-frequency gain.
-   Attack: sets the effect onset time.
-   Release: sets the effect release time.

### EQ Parameters

1.  Classic 5-band EQ editor
2.  Tap to select nodes 1–5.
3.  Adjust the parameters for the selected frequency band.
    -   Assign: applies the EQ output type
    -   Type:
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image30.png" alt="XRecer user interface" width="48"/> Peak: smoothly adjusts the frequency band affected by the node
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image31.png" alt="XRecer user interface" width="48"/> Hi-Pass: cuts frequencies to the left of the node (low frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image32.png" alt="XRecer user interface" width="48"/> Lo-Pass: cuts frequencies to the right of the node (high frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image33.png" alt="XRecer user interface" width="48"/> Hi-Shelf: attenuates frequencies to the right of the node (high frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image34.png" alt="XRecer user interface" width="48"/> Lo-Shelf: attenuates frequencies to the left of the node (low frequencies)
    -   Gain: boosts or cuts this frequency band
    -   Freq: sets the frequency controlled by the node
    -   Q: sets the bandwidth covered by the node
    -   Bypass: disables this EQ band.

## FX Chain Input/Output
<ManualImage className="manual-figure" src="/img/manual/image35.png" alt="XRecer user interface" width="300"/>

Flexible input and output settings provide multichannel audio I/O control and integration with external devices. XRecer can be used with any external device that sends or receives audio through a hardware or Bluetooth connection.

### Selecting an Input

1.  Mono: when a mono input is selected, the audio signal defaults to the left-channel input.
2.  Stereo: 1/2 represent the left/right channels, respectively.

### Input Parameters

Tap and hold the input block to open its parameter editor. Noise-reduction parameters are provided by default for each FX Chain input.

1.  General parameters:
    -   Gain: sets the input gain
    -   Noise Gate: turns the noise gate on or off
    -   Attack: sets how quickly the noise gate opens
    -   Release: sets how quickly the noise gate closes
    -   Threshold: sets the noise-gate trigger threshold

1.  Special parameters

    -   Impedance \[Ω\]: impedance range, 10K–10M.
    -   Position: the minimum and maximum values of the expression pedal. Move the expression pedal through its full travel to measure the minimum and maximum positions. Tap Recalibrate to reset them.

###  Selecting an Output

<ManualImage className="manual-figure" src="/img/manual/image36.png" alt="XRecer user interface" width="300"/>

Same as the FX Chain input.

### Output Parameters

1.  General parameters

    -   Volume
    -   PAN: left/right channel balance
    -   MUTE: mutes this signal path
    -   SOLO: outputs only this signal path and mutes all others
        -   LEVEL \[dB\]: sets the output gain.
        -   GROUND LIFT switch: turn on to reduce/eliminate ground-loop noise.
    -   LEVEL Status: displays the output level on the level meter.

2.  Special parameters

    -   MIDI THRU switch: when enabled, received MIDI messages are forwarded automatically.

## Split and Merge

### Basic Operations

<ManualImage className="manual-figure" src="/img/manual/image19.png" alt="XRecer user interface" width="600"/>

1.  Drag the Split point after the input block or the Merge point before the output block to split or merge this signal path with another.
2.  Drag a Split or Merge point to change its position.
3.  Split/Merge supports up to two adjacent signal paths.

### Merge Parameters

<ManualImage className="manual-figure" src="/img/manual/image37.png" alt="XRecer user interface" width="600"/>

1.  Signal A: signal path A volume
2.  Pan A: left/right channel balance for signal path A
3.  Signal B: signal path B volume
4.  Pan B: left/right channel balance for signal path B
5.  Phase Flip: inverts the phase of signal path B
6.  Level: output volume after the Merge

###  Split Parameters

<ManualImage className="manual-figure" src="/img/manual/image38.png" alt="XRecer user interface" width="600"/>

1.  Type: Balance, A/B, Crossover
2.  Stereo:

    -   Split: routes the left channel to signal path A and the right channel to signal path B.
    -   Normal: routes both left and right channels to signal paths A/B.

1.  Balance:

    -   Available only when Type is set to Balance.
    -   Sets the relative audio signal levels for signal paths A/B.

2.  Signal to A/Signal to B:

    -   Available only when Type is set to A/B.
    -   Controls the volume of signal paths A/B independently.

3.  Frequency:

    -   Available only when Type is set to Crossover.
    -   Specifies the high-pass/low-pass frequency.

4.  Mode: sets High-Pass/Low-Pass.
