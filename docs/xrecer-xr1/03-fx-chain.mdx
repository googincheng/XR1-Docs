# Signal Chain

<ManualImage className="manual-figure" src="/img/manual/image8.png" alt="XRecer user interface" width="600"/>

## Overview

<ManualImage className="manual-figure" src="/img/manual/image9.png" alt="XRecer user interface" width="200"/>

1.  #### Scene / Preset / Stomp / Combo modes

    -   These modes make it much easier to switch tones quickly while you play.
    -   Four modes are available: Scene, Preset, Stomp, and Combo.
    -   Tap and hold to access Mode Editor and create a Combo mode.
    -   See Live View for details.

<ManualImage className="manual-figure" src="/img/manual/image10.png" alt="XRecer user interface" width="300"/>

2.  #### Preset number

    -   A Preset number such as P01-12 has two parts.
    -   P01 is the patch number. Each patch contains 16 Presets.
    -   12 is the Preset number inside the current patch.
    -   Tap to browse all Presets.
    -   An asterisk (*) means the current changes have not been saved.

3.  #### Save Preset button

    -   Save: tap to save all changes to the current Preset.
    -   Save As: tap to create and save a new Preset.

4.  #### More button

    -   Copy Preset/Scene: tap to copy all settings from the current Preset or Scene.
    -   Paste Preset/Scene: tap to paste the copied settings into the current Preset or Scene.
    -   Performance Mode: same as item 1.
    -   MIDI Out: tap to edit the MIDI messages sent by the footswitches and expression pedals, for linking with other devices. See MIDI Out.

<ManualImage className="manual-figure" src="/img/manual/image11.png" alt="XRecer user interface" width="60"/>

5.  #### Scene button

    -   You can save different parameter settings of the current Signal Chain to different Scenes and switch between them quickly — up to 16 Scenes: 1A–8A and 1B–8B (pages 1 and 2).
    -   In Scene mode, tap this button to switch Scenes.

6.  #### Undo / Redo buttons

<ManualImage className="manual-figure" src="/img/manual/image12.png" alt="XRecer user interface" width="300"/>

7.  #### MIC OUT volume

    -   Sets the microphone output (MIC OUT) level.
    -   Tap and hold to access the dedicated microphone Signal Chain. That chain has its own input and output.

8.  #### Global output volume

    -   Sets the level of OUT 1/2, OUT 3/4, SEND 1/2, PHONES, CapX Out, and USB Out.

9.  #### BPM

    -   Shows the tempo in beats per minute (BPM). Tempo can be stored globally, with the Preset, or with the Scene.

10.  #### Preset name

<ManualImage className="manual-inline-icon" src="/img/manual/image13.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image14.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image15.png" alt="XRecer user interface" width="48"/>

11.  #### Effect block

    -   XRecer includes an extensive range of effects that closely reproduce their analog counterparts. Select an effect and adjust its parameters to create a tone that is uniquely yours.
    -   Tap: open the parameter editor. See Parameter Definitions.
    -   Double-tap: bypass or activate the effect.
        -   Bypass: the effect is bypassed (Figure 2).
        -   Mute: the entire audio path is muted (Figure 3).
    -   Tap and hold, then drag to move the effect in the Signal Chain.
    -   Tap and hold to open a menu:
        -   Copy / Paste
        -   Replace Effect
        -   Rename

  <ManualImage className="manual-inline-icon" src="/img/manual/image16.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image17.png" alt="XRecer user interface" width="48"/> <ManualImage className="manual-inline-icon" src="/img/manual/image18.png" alt="XRecer user interface" width="48"/>

12.  #### Signal Chain input

    -   Tap + to select one or more inputs for the Signal Chain.
    -   Stereo (Figure 2) and mono (Figure 3) are supported.
    -   Double-tap to mute the input (Figure 4).
    -   After you select an input, tap it to edit its parameters. See Input Parameters.
    -   Tap and hold, then drag to create a split or merge.

13.  #### Signal Chain output

    Output selection uses the same operations as the input.

<ManualImage className="manual-figure" src="/img/manual/image19.png" alt="XRecer user interface" width="600"/>

14.  #### Split and Merge

    -   Split and Merge let you place effects in series or in parallel.
    -   Tap and hold the Split control, then drag it to create a parallel path.
    -   Tap and hold the Merge control, then drag it to merge this path into another path.
    -   Tap a Split or Merge point to access its parameters.
    -   Tap and hold a Split or Merge point, then drag it to a new position.
    -   Split and Merge work only between two adjacent paths. You cannot route between non-adjacent paths, such as path 1 and path 3.

15.  #### Tap an empty area to add an effect

<ManualImage className="manual-figure" src="/img/manual/image20.png" alt="XRecer user interface" width="400"/>

16.  #### LOOP path

    -   Tap the input and select LOOP to create a LOOP path. You can place the sections you have recorded on this path. While you play, you can layer playback of multiple Loop Files.

### Parameter Definitions

#### Common parameters

-   Gain: sets the gain amount of the selected device.
-   Drive / Overdrive: sets the overdrive amount of the selected device.
-   Tone / Treble: controls the high frequencies. This control can pass all highs, or cut a large amount of highs and some upper mids.
-   Volume / Master: sets the overall volume of the selected device.
-   Comp: determines the amount of gain reduction.
-   Threshold: sets the threshold.
-   Rate: adjusts the speed of the effect. Higher settings are faster.
-   Depth: adjusts the intensity of the modulation effect. Higher settings are more pronounced.
-   Sync: syncs the effect speed to the current BPM.
-   Value: limited by the range of the Tempo and Speed parameters.
-   Feedback / Mix / Blend: adjusts the proportion of the delayed signal. Higher settings increase the mix proportion.
-   Decay: sets how long the effect lasts.
-   Pre-Delay: sets the delay before the effect starts.
-   High-Pass / Low-Pass: control the frequency range of the high-pass and low-pass filters.
-   Tail: allows delay or reverb tails to decay naturally.
-   Bypass: bypasses the entire effect block.

### EQ Parameters

1.  Five-band EQ editor
2.  Tap to select bands 1–5.
3.  Adjust the selected band.
    -   Assign: selects the output or outputs the EQ is applied to
    -   Type:
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image30.png" alt="XRecer user interface" width="26"/> Peak: smoothly adjusts the band affected by the node
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image31.png" alt="XRecer user interface" width="26"/> Hi-Pass: cuts the band to the left of the node (low frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image32.png" alt="XRecer user interface" width="26"/> Lo-Pass: cuts the band to the right of the node (high frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image33.png" alt="XRecer user interface" width="26"/> Hi-Shelf: attenuates the band to the right of the node (high frequencies)
        -   <ManualImage className="manual-inline-icon" src="/img/manual/image34.png" alt="XRecer user interface" width="26"/> Lo-Shelf: attenuates the band to the left of the node (low frequencies)
    -   Gain: boosts or cuts this band
    -   Freq: the frequency the node controls
    -   Q: the bandwidth the node covers
    -   Bypass: bypasses this band

## Signal Chain Input / Output
<ManualImage className="manual-figure" src="/img/manual/image35.png" alt="XRecer user interface" width="300"/>

Flexible input and output settings let you control multiple audio channels at once and link up with other external devices. Any device that can send or receive audio through a hardware jack or Bluetooth can work with XRecer.

### Select an Input

1.  Mono: a mono input is routed to the left channel by default.
2.  Stereo: 1 is the left channel and 2 is the right channel.

### Input Parameters

Tap and hold the input to access its parameters. Each Signal Chain input includes a noise gate by default.

1.  Common parameters:
    -   Gain: sets the input gain
    -   Noise Gate: turns the noise gate on or off
    -   Attack: sets how quickly the noise gate opens
    -   Release: sets how quickly the noise gate closes
    -   Threshold: sets the level that opens the noise gate

2.  Special parameters

    -   Impedance [Ω]: input impedance, 10 kΩ–10 MΩ.
    -   Position: lowest and highest values of an expression pedal. Move the pedal from heel to toe, then tap Recalibrate if you need to measure again.

### Select an Output

<ManualImage className="manual-figure" src="/img/manual/image36.png" alt="XRecer user interface" width="300"/>

Output selection uses the same steps as input selection.

### Output Parameters

1.  Common parameters

    -   Volume: sets the output level
    -   Pan: sets the left/right balance
    -   Mute: mutes this path
    -   Solo: outputs only this path and mutes the others
    -   Level [dB]: sets the output gain
    -   Ground Lift: reduces or removes ground-loop noise
    -   Level meter: shows the current output level

2.  Special parameters

    -   MIDI THRU: when enabled, incoming MIDI messages are forwarded.

## Split and Merge

### Basic Operation

<ManualImage className="manual-figure" src="/img/manual/image19.png" alt="XRecer user interface" width="600"/>

1.  Drag the Split point after the input, or the Merge point before the output, to join this path with an adjacent path.
2.  Drag a Split or Merge point to move it.
3.  Split and Merge support two adjacent paths.

### Merge Parameters

<ManualImage className="manual-figure" src="/img/manual/image37.png" alt="XRecer user interface" width="600"/>

1.  Signal A: level of path A
2.  Pan A: left/right balance of path A
3.  Signal B: level of path B
4.  Pan B: left/right balance of path B
5.  Phase Flip: reverses the polarity of path B
6.  Level: output level after the paths are merged

### Split Parameters

<ManualImage className="manual-figure" src="/img/manual/image38.png" alt="XRecer user interface" width="600"/>

1.  Type: Balance, A/B, or Crossover
2.  Stereo:

    -   Split: sends the left channel to path A and the right channel to path B.
    -   Normal: sends both left and right channels to paths A and B.

3.  Balance:

    -   Available only when Type is Balance.
    -   Sets how much signal is sent to path A versus path B.

4.  Signal to A / Signal to B:

    -   Available only when Type is A/B.
    -   Sets the level sent to path A and path B separately.

5.  Frequency:

    -   Available only when Type is Crossover.
    -   Sets the crossover frequency for the high-pass and low-pass filters.

6.  Mode: sets High-Pass or Low-Pass.
