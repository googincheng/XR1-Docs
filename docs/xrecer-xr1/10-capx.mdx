# CapX

CapX uses AI training to capture your preferred analog tone and save it to the XR1 for live performance.

## Procedure

#### Connect the equipment by following the on-screen instructions. (When connecting a Tube AMP, observe its input and output voltage requirements to avoid damaging the equipment.)

1.  #### Before starting the capture, verify that the audio signals are at suitable levels. Use the parameters below to make any necessary adjustments.

<img className="manual-figure" src="/img/manual/image73.png" alt="XRecer user interface" width="600"/>
    -   Input Level: Adjusts the instrument input level to prevent clipping

    -   Mic In Level: Adjusts the microphone input level to prevent clipping

    -   Inst Level: Displays the instrument input signal level

    -   Cap Level: Displays the processed input signal level

    -   NAM Train: Trains the capture with Neural Amp Modeler, developed by Steven Atkinson

    -   CAPX Train: Trains the capture with XRecer's proprietary tone-capture algorithm

2.  #### Ready

     <img className="manual-figure" src="/img/manual/image74.png" alt="XRecer user interface" width="600"/>

    -   Do not operate the equipment during training. If you are using a microphone, keep the environment quiet until recording is complete.

    -   If training fails, adjust Gain so the Wet Signal is neither too low nor clipping.

    -   Tap PREV to stop training and return to SETTING.

3.  #### Completed

<img className="manual-figure" src="/img/manual/image75.png" alt="XRecer user interface" width="600"/>

    -   CapX: Tap to audition the captured model.

    -   Target Device: Tap to audition the external target device.

    -   Level: Adjusts the audition output level.

    -   Not good Enough, try again: Tap to retrain the capture.

    -   SAVE: Tap to save the captured tone to File Manager. You can then select and add this Effect to the FX Chain.

## Using a CapX/NAM Effect

In FX Chain > Select Effect, tap the NAM or CapX category to view all models of that type stored on the device.
