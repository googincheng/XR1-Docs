# Global EQ

<ManualImage className="manual-figure" src="/img/manual/image29.png" alt="XRecer user interface" width="600"/>

Global EQ applies to all outputs except the dry DI channels. It is a classic five-band EQ. Drag any node to adjust it, or tap a node for precise parameter editing:

1.  Five-band EQ editor

2.  Tap to select bands 1–5

3.  Adjust the selected band

    -   Assign: the output the EQ is applied to

    -   Type:

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image30.png" alt="XRecer user interface" width="30"/> Peak: smoothly adjusts the band affected by the node

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image31.png" alt="XRecer user interface" width="30"/> Hi-Pass: cuts the band to the left of the node (low frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image32.png" alt="XRecer user interface" width="30"/> Lo-Pass: cuts the band to the right of the node (high frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image33.png" alt="XRecer user interface" width="30"/> Hi-Shelf: attenuates the band to the right of the node (high frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image34.png" alt="XRecer user interface" width="30"/> Lo-Shelf: attenuates the band to the left of the node (low frequencies)

    -   Gain: boosts or cuts this band (the Y axis)

    -   Freq: the frequency the node controls

    -   Q: the bandwidth the node covers

    -   Bypass: disables the node
