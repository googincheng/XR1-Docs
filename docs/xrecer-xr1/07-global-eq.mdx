# Global EQ

<ManualImage className="manual-figure" src="/img/manual/image29.png" alt="XRecer user interface" width="600"/>

Global EQ processes all outputs except the dry DI channels. It provides five bands of EQ. Drag a node to adjust it, or tap a node for precise parameter control:

1.  Five-band EQ editor

2.  Tap to select nodes 1–5

3.  Adjust the selected band's parameters

    -   **Assign**: Selects the output connectors to which Global EQ is applied

    -   **Type**:

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image30.png" alt="XRecer user interface" width="30"/> Peak: Boosts or attenuates a frequency range centered on the node

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image31.png" alt="XRecer user interface" width="30"/> Hi-Pass: Cuts frequencies below the node (low frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image32.png" alt="XRecer user interface" width="30"/> Lo-Pass: Cuts frequencies above the node (high frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image33.png" alt="XRecer user interface" width="30"/> Hi-Shelf: Attenuates the frequency range above the node (high frequencies)

        -   <ManualImage className="manual-inline-icon" src="/img/manual/image34.png" alt="XRecer user interface" width="30"/> Lo-Shelf: Attenuates the frequency range below the node (low frequencies)

    -   **Gain**: Boosts or attenuates the selected band; represented by the node's Y-axis position

    -   **Freq**: Sets the node's frequency

    -   **Q**: Sets the bandwidth affected by the node

    -   **Bypass**: Bypasses the selected band

4.  <ManualImage className="manual-inline-icon" src="/img/manual/image64.png" alt="XRecer user interface" width="30"/> Bypass Global EQ

5.  <ManualImage className="manual-inline-icon" src="/img/manual/image65.png" alt="XRecer user interface" width="30"/> Reset all parameters
